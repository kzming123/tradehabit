# TradeHabit — UI Guidelines

# Design Style

Inspired by:

* Linear
* Stripe
* Coinbase
* Notion

The UI should feel:

* modern
* calm
* spacious
* premium
* minimal

---

# Layout Rules

## Use:

* clean spacing
* modular cards
* subtle borders
* rounded corners
* strong typography

## Avoid:

* clutter
* noisy gradients
* too many colors
* excessive animations

---

# Dashboard Style

Dashboard should feel:

* motivating
* performance-oriented
* clean
* focused

Use:

* KPI cards
* clean charts
* recent activity
* minimal widgets

---

# Form Style

Forms must feel:

* fast
* low friction
* mobile friendly

Group related inputs clearly.

---

# Color Direction

Dark mode first.

Use:

* neutral dark backgrounds
* subtle contrast
* green/red pnl highlights

Avoid:

* oversaturated neon colors

---

# UX Philosophy

Less is more.

Prioritize:

* clarity
* usability
* simplicity
* speed
